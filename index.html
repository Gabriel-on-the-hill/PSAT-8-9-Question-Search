What's in this folder

Open search.html
The search page. Live search across question, passage/figure, choices, explanation, skill, canonical ID & retired ID; skill + PSAT difficulty + trust filters; three sort modes; each result expands to the full question with the correct answer marked and the explanation.
 Doc SEARCH-and-IMPROVEMENTS.md
What was built & verified, plus a prioritized audit of speed, accuracy, and effectiveness improvements for the app in real-time use.

The other files here — style.css, nav.js, the four data-*.js banks and assets/ — are copies of the app's own files that search.html reads so it can run standalone. (gate.js and anti-cheat.js are leftovers: nothing loads them any more, and they can be deleted.)

Standalone. Nothing in the practice app links to or depends on this page. To use it, just open search.html — no password. To retire it, delete this folder — the app is unaffected.

Tested: every question in the bank loads and searches correctly · results render as plain text, with no correct-answer flag and no search-term marks · all JS passes node --check.
